# Avatar Pixel Parts

Layered pixel avatar assets for the demo app.

All SVGs use the same canvas: `144 x 240`.

Suggested render order:

1. `body/base_body.svg`
2. `clothes/shirt_template.svg`
3. `clothes/shorts_template.svg`
4. `eyes/*.svg`
5. `hair/*.svg`
6. `glasses/*.svg`

The shirt and shorts templates use CSS variables:

- `--shirt`
- `--shirtDark`
- `--shirtLight`
- `--pants`
- `--pantsDark`
- `--pantsLight`
