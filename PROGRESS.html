Bugs & Issues

Bug
Bike-Grafik im Editor sieht schlecht aus
Die PixelBike.tsx SVG-Komponente ist hand-coded und wirkt unproportional und unprofessionell. Sie muss durch eine bessere Lösung ersetzt werden.

Optionen:
  • Option A (empfohlen): Echte Pixel-Art als PNG-Sprites (wie Hardtail.png / Enduro.png) mit Farboverlay-Technik — z.B. eine Maske/Tint-Layer in React Native via tintColor oder ein zweischichtiges Image (Silhouette + Farblayer)
  • Option B: SVG-Datei extern designen (Figma/Aseprite → SVG Export) und als statische SVG-Datei einbinden, Farbe via Props
  • Option C: Bessere Hand-coded SVG mit mehr Liebe zum Detail (aufwändig)
  • Option D: Vorerst die statischen Hardtail/Enduro/Downhill.png zeigen (sehen gut aus!) — Farbvorschau weglassen bis Lösung steht
Priorität: HochBike EditorUI
Bug
Neue Registrierungen erstellen kein Profil-Dokument
initProfile schlägt fehl wenn die Function den x-appwrite-key Header (restricted scope) statt des eigenen API Keys verwendet. Workaround ist deployed (API-Key Priorität gefixt), aber bei neuen Usern manuell zu testen. AuthBackend
Bug
BikeConfigurator (altes Inline-Widget) noch im Code
components/BikeConfigurator.tsx ist noch vorhanden aber vom Profil-Screen entfernt. Sollte aufgeräumt werden — entweder löschen oder in den neuen Bike Editor integrieren. Der Import ist bereits entfernt. Cleanup
